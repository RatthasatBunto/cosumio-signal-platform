# COSUMIO Signal Platform

COSUMIO is a personal web-based trading signal platform built to experiment with multi-timeframe market analysis, real-time data processing, and rule-based trading logic.

## Features

- Multi-timeframe market analysis
- Real-time market data handling
- Trading signal generation
- Risk / reward calculations
- Multiple trading strategy playbooks
- Web-based signal dashboard
- API integration
- Debugging and strategy testing

## Technologies

- JavaScript
- Node.js
- HTML / CSS
- REST APIs
- WebSocket data
- JSON configuration
- PowerShell for deployment and maintenance

## What I Worked On

I designed and developed the platform as a personal software project.

My work included:

- Working with real-time data

This project is actively being developed and used as a learning project for web development, APIs, automation, and software debugging.
